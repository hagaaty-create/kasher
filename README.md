# نظام نقاط البيع والكاشير المتقدم لمطاعم الشاورما والكريب (TADBEER POS)

نظام POS محلي احترافي (Offline-First) مصمم خصيصاً لمطاعم الوجبات السريعة (شاورما، كريب، برجر، مشروبات) يدعم الاتصال المباشر بالطابعات الحرارية (80mm Thermal Printers) وأوامر ESC/POS ودرج النقدية و QZ Tray.

---

## 🚀 المميزات الرئيسية
1. **دعم كامل Offline بدون إنترنت**:
   - يعمل مباشرة داخل المتصفح بالكامل ويخزن جميع الأصناف والطلبات والإعدادات محلياً.
2. **نظام الطباعة الحرارية (80mm POS Thermal Receipt)**:
   - دعم بروتوكول **QZ Tray** الرسمي على `localhost:8181`.
   - توليد أوامر **ESC/POS** المباشرة لقاطع الورق الالي ودرج النقدية والتنبيهات الصوتية.
   - دعم طباعة Window Print / iframe كخيار بديل عند عدم وجود QZ Tray.
   - طباعة تذاكر المطبخ (Kitchen Order Ticket - KOT).
3. **شاشة المطبخ الذكية (Kitchen Display System - KDS)**:
   - متابعة حية للطلبات بالتوقيت المنقضي والتحكم التفاعلي بالبث التنازلي للتأخير.
   - تنبيه صوتي فوري عند إرسال طلب جديد للمطبخ.
4. **شاشة كاشير سريعة مخصصة للمس (Touch Friendly)**:
   - اختصارات لوحة المفاتيح: `F1` (طلب جديد)، `F4` (إتمام الطلب والدفع)، `F9` (تأكيد وطباعة الفاتورة).
   - تقسيم الأصناف حسب الأقسام (شاورما، كريب، برجر، مشروبات، مقبلات).
5. **التقارير وتقفيل الورديات**:
   - إحصائيات المبيعات ومتوسط الفاتورة وعدد الطلبات.
   - تصدير بيانات المبيعات مباشرة بصيغة Excel (CSV).

---

## 🛠️ كيفية التشغيل وتوصيل الطابعة الحرارية

### 1. تشغيل نظام الكاشير:
افتضاح ملف `index.html` المباشر عبر المتصفح (Chrome / Edge) أو تشغيله عبر سيرفر محلي.

### 2. إعداد طابعة الفواتير (80mm ESC/POS):
1. قم بتوصيل طابعة الفواتير (مثل Xprinter, Epson TM-T20, Bixolon, GPrinter, Rongta) بجهاز الكاشير عبر USB أو Ethernet.
2. ثبت تعريف الطابعة المباشر على نظام الويندوز وتأكد من تسميتها (مثل: `POS-80 Printer`).
3. نزل وثبت برنامج **QZ Tray** المجاني من الموقع الرسمي [qz.io](https://qz.io).
4. افتح شاشة "إعدادات الطابعة" في نظام الكاشير وأدخل اسم الطابعة لربطها وتجربة الطباعة المباشرة.
