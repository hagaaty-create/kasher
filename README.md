# نظام نقاط البيع والحسابات الشامل لمطاعم الشاورما والكريب (TADBEER POS)

نظام POS محلي احترافي (Offline-First) ومكتمل الخدمات مصمم خصيصاً لمطاعم الوجبات السريعة (شاورما، كريب، برجر، مشروبات). يدعم الحسابات الكاملة، تقفيل الورديات وتصفير الدرج، وإدارة الأصناف والأسعار، مع الاتصال المباشر بالطابعات الحرارية (80mm Thermal Printers) وأوامر ESC/POS ودرج النقدية و QZ Tray.

---

## 🚀 المميزات المكتملة والنظام الجاهز للإطلاق

1. **نظام الكاشير الرئيسي (Main POS)**:
   - إضافة سريعة للأصناف وتعديل الكميات وحذف العناصر.
   - دعم التيك أواي والصالة والتوصيل وطرق الدفع المختلفة (كاش، فيزا، محفظة إلكترونية).
   - اختصارات لوحة المفاتيح: `F1` (طلب جديد)، `F4` (إتمام الطلب والدفع)، `F9` (تأكيد وطباعة الفاتورة).
   - بدون أي نسبة ضريبة (تم حذف الـ 14% ضريبة نهائياً).

2. **نظام تقفيل الوردية وحسابات الدرج (Shift Management & Cash Zeroing)**:
   - احتساب مبيعات كاش الوردية الحالية والإيداعات ومسحوبات النثريات والمصروفات.
   - إمكانية تسجيل حركة نقدية بالدرج (سحب مصروفات أو إيداع مالي).
   - عند الضغط على **"تقفيل اليوم والوردية"**: يتم حفظ الوردية في الأرشيف **وتصفير عهدة الدرج ومبيعات الوردية كلياً** لتبدأ الوردية الجديدة من الصفر تماماً.

3. **لوحة الإدارة والمالية الشاملة للـ Admin**:
   - متابعة دقيقة لـ (إجمالي المبيعات + المصروفات والنثريات + الإيداعات + صافي الأرباح).
   - فلترة مخصصة حسب الفترات: (كل الأوقات / مبيعات اليوم فقط / مبيعات الشهر الحالي).
   - جدول تفصيلي لكافة الحركات المالية (داخل وخارج) وأرشيف الإغلاق السابق.

4. **إدارة الأصناف وقائمة الطعام والأسعار (Products & Prices Admin)**:
   - إمكانية إضافة أصناف جديدة، تعديل الأوصاف والأسعار والصور، أو حذف أي صنف من المطعم مباشرة بدون الحاجة للتعديل في الكود.

5. **نظام الطباعة الحرارية (80mm POS Thermal Receipt)**:
   - دعم بروتوكول **QZ Tray** على `localhost:8181`.
   - توليد أوامر **ESC/POS** المباشرة لقاطع الورق الآلي ودرج النقدية (`\x1B\x70\x00\x19\xFA`).
   - دعم طباعة Window Print Iframe كخيار بديل تلقائي بدون مشاكل.

6. **تصدير التقارير والبيانات**:
   - تصدير بيانات المبيعات والحسابات مباشرة بصيغة **Excel (CSV)** وتلخيص الورديات واليوميات.

## 🛠️ كيفية التشغيل وتوصيل الطابعة الحرارية

### 1. تشغيل السيستم:
افتضاح ملف `index.html` مباشرة في متصفح (Chrome / Edge) أو تشغيله عبر سيرفر محلي.

### 2. إعداد طابعة الفواتير (80mm ESC/POS):
1. قم بتوصيل طابعة الفواتير (مثل Xprinter, Epson TM-T20, Bixolon, GPrinter, Rongta) بجهاز الكاشير عبر USB أو Ethernet.
2. ثبت تعريف الطابعة المباشر على نظام الويندوز وتأكد من تسميتها (مثل: `POS-80 Printer`).
3. نزل وثبت برنامج **QZ Tray** المجاني من الموقع الرسمي [qz.io](https://qz.io).
4. افتح شاشة "إعدادات الطابعة" في نظام الكاشير وأدخل اسم الطابعة لربطها وتجربة الطباعة المباشرة.
